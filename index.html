Midnight Delivery · Project notes

About the project

Midnight Delivery is a Christmas Marathon project for Computer Game Technology Engineering. It is a short arcade game about guiding a sleigh through a snowy village and picking up presents.

Objective
Collect at least ten gifts and survive the 45-second run. Stars add bonus points. Hitting ice costs one of your three lives.
Controls
Use the left and right arrow keys, A and D, or the on-screen buttons to change lanes. You can pause the run or play again when it ends.
Game engineering
HTML and CSS build the interface. JavaScript draws the scene on a 2D canvas and uses elapsed time to update object positions. Each encounter checks the object’s lane and whether it has reached the sleigh.
Running the game
Open the HTML file in a browser. It works offline and saves your best score in the current browser when local storage is available.
